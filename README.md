<h1>Ride Mate - Ride Booking Website</h1>

<p >
  <b>A modern ride booking platform built with React, Redux, and TypeScript.</b><br/>
  <i>Features role-based dashboards for Riders, Drivers, and Admins with smooth UI, live ride updates, and analytics.</i>
</p>

<hr/>

<h2>Tech Stack</h2>

<ul>
  <li><b>Frontend:</b> React, Redux Toolkit, TypeScript</li>
  <li><b>API Handling:</b> Axios, RTK Query</li>
  <li><b>UI & Styling:</b> Tailwind CSS, Shadcn</li>
  <li><b>Form Validation:</b> Zod</li>
  <li><b>Charts & Analytics:</b> Recharts</li>
</ul>

<hr/>

<h2>Features</h2>

<h3>Rider</h3>
<ul>
  <li>Register & Login</li>
  <li>Profile management & password reset</li>
  <li>Current ride view & restrictions (cannot request new ride if one is active)</li>
  <li>Ride request & cancellation control</li>
  <li>Emergency police contact</li>
  <li>Ride history with search functionality</li>
  <li>Live location sharing</li>
</ul>

<h3>Driver</h3>
<ul>
  <li>Register & Login</li>
  <li>Profile management & password reset</li>
  <li>View and accept ride requests</li>
  <li>Current ride details</li>
  <li>Ride history</li>
  <li>Active/Inactive status toggle (inactive drivers cannot see ride requests)</li>
  <li>Total analytics with Recharts</li>
</ul>

<h3>Public</h3>
<ul>
  <li>Home Page</li>
  <li>FAQ Page</li>
  <li>About Page</li>
  <li>Features</li>
  <li>Policy Page</li>
  <li>Contact Page</li>
</ul>

<h3>Admin</h3>
<ul>
  <li>Admin login (with rider login system)</li>
  <li>Analytics dashboard</li>
  <li>Manage Riders (search & update)</li>
  <li>Manage Drivers (search & update)</li>
  <li>Manage Contact Messages</li>
  <li>Profile update & password reset</li>
</ul>

<h3>Extra Features</h3>
<ul>
  <li>Role-based landing pages upon login</li>
  <li>JWT-based login and registration</li>
  <li>Role selection during registration (Rider/Driver)</li>
  <li>Role-based navigation with profile dropdown</li>
  <li>Interactive UI: carousels, dynamic ride cards, charts</li>
  <li>Toast/Alert messages for success & errors</li>
  <li>Loading skeletons for better UX</li>
</ul>
